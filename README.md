# Bot Chip 🤖
Um bot para Discord desenvolvido em Python com discord.py.  
Ele foi criado para automatizar interações e oferecer comandos personalizados dentro de servidores.

## 🚀 Funcionalidades
- Conexão com o Discord usando token seguro
- Comandos customizados para interação com usuários
- Sistema de ajuda integrado (`c+help`)
- Estrutura simples e fácil de expandir

## 📂 Estrutura do projeto
```Codigo/
 ├── bot.py              # Arquivo principal do bot
 ├── client_secret.json  # Credenciais de autenticação
 ├── token.pkl           # Token salvo
.env                     # Configurações locais
.gitignore               # Arquivos e pastas ignorados
README.md                # Documentação do projeto
```
## ▶️ Uso
No Discord, digite: "c+help"

para ver todos os comandos disponíveis.
